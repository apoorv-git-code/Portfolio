# Personal Portfolio 🚀

Welcome to the repository for my personal web developer portfolio! This website serves as a digital resume to showcase my skills, projects, and professional background.

## 🔗 Live Demo
[Click here to view the live website!](https://portfolio-apoorv-mishra.vercel.app/)

## 🛠️ Technologies Used
This project was built using standard web technologies:
* **HTML5:** For the structure and content (`index.html`).
* **CSS3:** For styling, layout, and responsive design (`style.css`).
* **JavaScript:** For interactive elements and dynamic functionality (`script.js`).

## ✨ Features
* **Responsive Design:** Fully optimized for desktops, tablets, and mobile devices.
* **Project Gallery:** A dedicated section showcasing my recent work and code repositories.
* **Interactive UI:** Smooth scrolling and dynamic animations.
* **Contact Section:** Easy ways to reach out to me directly.
